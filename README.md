# Interaktive Animationen – Chemie, Biologie & Informatik

Eine Sammlung interaktiver Animationen und Simulationen für den Unterricht in der Sekundarstufe I und II. Jede Animation ist eine einzelne HTML-Datei, die ohne Installation direkt im Browser läuft.

**Die Webseite ist auf Deutsch.**

**Live ansehen:** https://makro5652.github.io/animationen/

## Nutzung

- **Online:** Die Startseite [`index.html`](index.html) listet alle Animationen nach Fach und Thema auf. Sie ist über GitHub Pages erreichbar (siehe Link oben).
- **Lokal:** Das Repository herunterladen oder klonen und `index.html` im Browser öffnen. Es ist kein Build und kein Server nötig.

```bash
git clone https://github.com/makro5652/animationen.git
```
